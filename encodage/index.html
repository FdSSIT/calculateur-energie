Encodage des données

Met à jour les prix lus par le calculateur public. Chargez le classeur Excel, vérifiez ce qui a été lu, puis téléchargez le fichier de données à déposer en ligne.

Cette page n'enregistre rien en ligne. Tout se passe dans votre navigateur : aucune donnée n'est envoyée nulle part. Pour que le calculateur public voie vos modifications, il faut déposer le fichier donnees.json produit à l'étape 3 dans le dépôt GitHub du site.
1

Charger le classeur

Format attendu : une ligne par mois, les colonnes du modèle, dans l'ordre. Le fichier .xlsx est lu directement — inutile de passer par un CSV.

Télécharger le modèle Excel
Déposez le fichier .xlsx ici ou cliquez pour le choisir
2

Vérifier et corriger

Les cellules sont modifiables. Une valeur vide est permise : le calculateur l'ignorera et signalera le mois comme non couvert. Les contrôles ci-dessous sont des signalements, pas des blocages.

3

Produire le fichier de données

Téléchargez donnees.json, puis déposez-le dans le dépôt GitHub du site, à la racine, en remplaçant l'ancien. Le calculateur l'utilise dès le rafraîchissement suivant.
